# Jellyfin Config Snapshot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Export the live Jellyfin configuration into `jellyfin/snapshot/` with every identifying value replaced by a placeholder, and restore it to any server from that snapshot plus a local `.env`.

**Architecture:** Four small stdlib-only Python modules in `jellyfin/scripts/`: `envfile` (read/append `.env`), `sanitize` (placeholder substitution and its inverse `fill`), `api` (Jellyfin HTTP client), and three entry points (`export.py`, `restore.py`, `check_secrets.py`). Export and restore take a client object, so tests drive them with an in-memory fake server built from synthetic fixtures.

**Tech Stack:** Python 3 standard library only (`urllib`, `json`, `re`, `pathlib`, `unittest`), git pre-commit hook, Jellyfin 10.11 REST API.

**Spec:** `docs/superpowers/specs/2026-10-14-jellyfin-config-snapshot-design.md`

## Global Constraints

- The repo is public: no API keys, tokens, passwords, private IPs, the user's domains, user names, user IDs, email addresses or media paths in any committed file — including tests, plans and READMEs.
- Python 3 standard library only; no `pip install`.
- Test fixtures must not contain literal private IPs, 32-hex strings, GUIDs or emails; build them at runtime (`'.'.join([...])`, `'ab' * 16`, `'someone' + '@' + ...`) so the leak checker passes on the test files themselves.
- Snapshot JSON is written with `indent=2, sort_keys=True` and a trailing newline.
- Scripts never print a secret value; they print names, labels and counts only.
- Placeholder syntax is `<NAME>` with `NAME` matching `[A-Z][A-Z0-9_]*`.
- Run all tests from the repo root with: `python3 -m unittest discover -s jellyfin/tests -t jellyfin/tests -v`

## Review Focus

- A secret in a field whose name does not contain key/token/password/secret (e.g. a webhook URL carrying `?token=`) must still be replaced — pinned by `test_query_string_token_replaced` in Task 2.
- A 32-hex value in a non-ID field (an API key in a free-text field) must become `<HEX_N>`, not be allowlisted — pinned by `test_hex_in_non_id_field_becomes_placeholder` in Task 2.
- Running export twice must produce byte-identical files and add nothing new to `.env` — pinned by `test_second_export_is_identical` in Task 4.
- A plugin whose configuration endpoint fails (disabled plugin) must not abort the export — pinned by `test_unreadable_plugin_config_is_skipped` in Task 4.
- Restore with a placeholder missing from `.env` must stop before any write, and a library/task missing on the target must be skipped, not crash — pinned by `test_missing_placeholder_aborts_without_posting` and `test_missing_library_is_skipped` in Task 6.

```python
"""Read and append KEY=value lines in jellyfin/.env."""
from pathlib import Path


def load(path):
    values = {}
    path = Path(path)
    if not path.exists():
        return values
    for line in path.read_text().splitlines():
        line = line.strip()
        if not line or line.startswith('#') or '=' not in line:
            continue
        key, value = line.split('=', 1)
        values[key.strip()] = value.strip()
    return values


def append(path, values):
    if not values:
        return
    path = Path(path)
    existing = path.read_text() if path.exists() else ''
    with path.open('a') as f:
        if existing and not existing.endswith('\n'):
            f.write('\n')
        for key, value in values.items():
            f.write(f'{key}={value}\n')
```

### Task 2: Sanitizer

**Files:**
- Create: `jellyfin/scripts/sanitize.py`
- Test: `jellyfin/tests/test_sanitize.py`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - Regexes `SECRET_KEY`, `SECRET_QUERY`, `PRIVATE_IP`, `EMAIL`, `GUID`, `PLACEHOLDER`.
  - `slug(text) -> str` (uppercase, non-alphanumerics → `_`, trimmed).
  - `norm_guid(text) -> str` (lowercase, dashes removed). `dashed(guid) -> str` (8-4-4-4-12 form).
  - `fill(obj, values: dict) -> obj` — replaces `<NAME>` in every string and dict key where `NAME in values`; leaves unknown placeholders untouched.
  - `Sanitizer(env, domains=(), users=(), libraries=(), literals=None)` where `users` and `libraries` are lists of `(name, id)`; `literals` is `{NAME: value}`.
  - `Sanitizer.sanitize(obj, context: str) -> obj`.
  - Attributes after sanitizing: `.new` (dict of env entries to append), `.used` (set of placeholder names emitted), `.kept_ids` (set of normalized GUIDs left in output).
  - Secret fields: names matching `SECRET_KEY` (api/auth/access/private/license/client key, token, password, secret) — a bare `Key` or `SortKey` is not a secret.
  - Placeholder names: secrets `<SLUG_OF_CONTEXT_AND_KEY_PATH>`; `<HOST_N>`, `<DOMAIN_N>`, `<EMAIL_N>`, `<HEX_N>`, `<USER_N>`; user IDs `<USER_N_ID>` (undashed) / `<USER_N_GUID>` (dashed); library IDs `<LIBRARY_<SLUG>_ID>` / `<LIBRARY_<SLUG>_GUID>`; literals by their given name. Env stores `USER_N=<name>` and `USER_N_ID=<normalized id>`; library IDs are not stored.

```python
"""Replace identifying values in Jellyfin config with <PLACEHOLDER> names.

Every real value is recorded (Sanitizer.env / .new) so restore.py can put it
back; the sanitized output contains no identifying values.
"""
import re

SECRET_KEY = re.compile(r'(?:api|auth|access|private|license|client)_?key|token|password|passwd|secret', re.I)
SECRET_QUERY = re.compile(r'([?&](?:api_?key|access_token|token|password)=)([^&\s"\'<>]+)', re.I)
PRIVATE_IP = re.compile(
    r'\b(?:10(?:\.\d{1,3}){3}|127(?:\.\d{1,3}){3}|192\.168(?:\.\d{1,3}){2}'
    r'|172\.(?:1[6-9]|2\d|3[01])(?:\.\d{1,3}){2})\b')
EMAIL = re.compile(r'[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}')
GUID = re.compile(
    r'\b(?:[0-9a-fA-F]{32}'
    r'|[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12})\b')
PLACEHOLDER = re.compile(r'<([A-Z][A-Z0-9_]*)>')
ID_FIELD = re.compile(r'ids?$', re.I)


def slug(text):
    return re.sub(r'[^A-Z0-9]+', '_', text.upper()).strip('_')


def norm_guid(text):
    return text.replace('-', '').lower()


def dashed(guid):
    g = norm_guid(guid)
    return f'{g[:8]}-{g[8:12]}-{g[12:16]}-{g[16:20]}-{g[20:]}'


def fill(obj, values):
    if isinstance(obj, dict):
        return {fill(k, values): fill(v, values) for k, v in obj.items()}
    if isinstance(obj, list):
        return [fill(v, values) for v in obj]
    if isinstance(obj, str):
        return PLACEHOLDER.sub(lambda m: values.get(m.group(1), m.group(0)), obj)
    return obj


class Sanitizer:
    def __init__(self, env, domains=(), users=(), libraries=(), literals=None):
        self.env = dict(env)
        self.new = {}
        self.used = set()
        self.kept_ids = set()
        self._by_value = {}
        for key, value in self.env.items():
            self._by_value.setdefault(value, []).append(key)
        self._ids = {}
        self._user_names = {}
        for name, uid in users:
            placeholder = self._name_for(name, 'USER')
            self._user_names[name] = placeholder
            self._remember(f'{placeholder}_ID', norm_guid(uid))
            self._ids[norm_guid(uid)] = placeholder
        for name, lid in libraries:
            self._ids[norm_guid(lid)] = f'LIBRARY_{slug(name)}'
        self._literals = []
        for name, value in (literals or {}).items():
            if value:
                self._remember(name, value)
                self._literals.append((name, value))
        self._literals.sort(key=lambda item: -len(item[1]))
        self._domains = [
            re.compile(r'(?<![A-Za-z0-9.-])(?:[A-Za-z0-9-]+\.)*' + re.escape(d) + r'(?![A-Za-z0-9-])', re.I)
            for d in domains if d]

    def sanitize(self, obj, context):
        return self._walk(obj, [slug(context)])

    def _remember(self, name, value):
        if self.env.get(name) != value:
            self.env[name] = value
            self.new[name] = value
            self._by_value.setdefault(value, []).append(name)

    def _name_for(self, value, prefix):
        pattern = re.compile(re.escape(prefix) + r'_(\d+)')
        for key in self._by_value.get(value, []):
            if pattern.fullmatch(key):
                return key
        taken = [int(m.group(1)) for key in self.env if (m := pattern.fullmatch(key))]
        name = f'{prefix}_{max(taken, default=0) + 1}'
        self._remember(name, value)
        return name

    def _ph(self, name):
        self.used.add(name)
        return f'<{name}>'

    def _secret(self, path, value):
        name = slug('_'.join(path))
        self._remember(name, value)
        return self._ph(name)

    def _walk(self, obj, path):
        if isinstance(obj, dict):
            out = {}
            for key, value in obj.items():
                new_key = self._text(key, path + [key], is_key=True) if isinstance(key, str) else key
                if (isinstance(value, str) and value and isinstance(key, str)
                        and SECRET_KEY.search(key) and not PLACEHOLDER.fullmatch(value)):
                    out[new_key] = self._secret(path + [new_key], value)
                else:
                    out[new_key] = self._walk(value, path + [new_key])
            return out
        if isinstance(obj, list):
            return [self._walk(value, path + [str(i)]) for i, value in enumerate(obj)]
        if isinstance(obj, str):
            return self._text(obj, path)
        return obj

    def _text(self, text, path, is_key=False):
        if text in self._user_names:
            return self._ph(self._user_names[text])
        for name, value in self._literals:
            if value in text:
                text = text.replace(value, self._ph(name))
        text = SECRET_QUERY.sub(
            lambda m: m.group(1) + self._secret(path + ['QUERY', m.group(1).strip('?&=')], m.group(2)),
            text)
        text = EMAIL.sub(lambda m: self._ph(self._name_for(m.group(0), 'EMAIL')), text)
        for domain in self._domains:
            text = domain.sub(lambda m: self._ph(self._name_for(m.group(0), 'DOMAIN')), text)
        text = PRIVATE_IP.sub(lambda m: self._ph(self._name_for(m.group(0), 'HOST')), text)
        field = next((p for p in reversed(path) if not p.isdigit()), '')
        return GUID.sub(lambda m: self._guid(m.group(0), field, is_key), text)

    def _guid(self, text, field, is_key):
        guid = norm_guid(text)
        suffix = 'GUID' if '-' in text else 'ID'
        if guid in self._ids:
            return self._ph(f'{self._ids[guid]}_{suffix}')
        if is_key or ID_FIELD.search(field):
            self.kept_ids.add(guid)
            return text
        return self._ph(self._name_for(text, 'HEX'))
```

```python
import json
import sys
import threading
import unittest
from http.server import BaseHTTPRequestHandler, HTTPServer
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / 'scripts'))
from api import ApiError, Client


class Handler(BaseHTTPRequestHandler):
    def log_message(self, *args):
        pass

    def _send(self, code, payload=None):
        body = b'' if payload is None else json.dumps(payload).encode()
        self.send_response(code)
        self.send_header('Content-Length', str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        if self.headers.get('Authorization') != 'MediaBrowser Token="k1"':
            return self._send(401)
        if self.path == '/Items?x=1':
            return self._send(200, {'ok': True})
        self._send(404)

    def do_POST(self):
        length = int(self.headers.get('Content-Length', 0))
        self.server.last_body = json.loads(self.rfile.read(length))
        self._send(204)


class ClientTest(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.server = HTTPServer(('localhost', 0), Handler)
        threading.Thread(target=cls.server.serve_forever, daemon=True).start()
        cls.url = f'http://localhost:{cls.server.server_port}/'

    @classmethod
    def tearDownClass(cls):
        cls.server.shutdown()

    def test_get_sends_token(self):
        self.assertEqual(Client(self.url, 'k1').get('Items?x=1'), {'ok': True})

    def test_error_hides_query(self):
        with self.assertRaises(ApiError) as ctx:
            Client(self.url, 'k1').get('Missing?userId=secret')
```

```python
"""Minimal Jellyfin REST client (stdlib only)."""
import json
import urllib.error
import urllib.request


class ApiError(Exception):
    pass


class Client:
    def __init__(self, base_url, api_key, timeout=30):
        self.base = base_url.rstrip('/')
        self.key = api_key
        self.timeout = timeout

    def get(self, path):
        return self._request('GET', path)

    def post(self, path, body):
        return self._request('POST', path, body)

    def _request(self, method, path, body=None):
        path = path.lstrip('/')
        data = None if body is None else json.dumps(body).encode()
        req = urllib.request.Request(f'{self.base}/{path}', data=data, method=method)
        req.add_header('Authorization', f'MediaBrowser Token="{self.key}"')
        if data is not None:
            req.add_header('Content-Type', 'application/json')
        try:
            with urllib.request.urlopen(req, timeout=self.timeout) as resp:
                raw = resp.read()
        except urllib.error.HTTPError as e:
            raise ApiError(f'{method} {path.split("?")[0]} -> HTTP {e.code}') from None
        return json.loads(raw) if raw else None
```

```python
"""Export live Jellyfin config to snapshot/, replacing identifying values with placeholders."""
import argparse
import json
import re
import sys
from pathlib import Path

import envfile
from api import ApiError, Client
from sanitize import Sanitizer

ROOT = Path(__file__).resolve().parents[1]
REQUIRED = ['JELLYFIN_URL', 'JELLYFIN_API_KEY', 'PRIVATE_DOMAINS', 'MEDIA_ROOT']


def plugin_filename(name):
    return re.sub(r'[^A-Za-z0-9]+', '-', name).strip('-').lower() + '.json'


def export(client, env, out_dir):
    info = client.get('System/Info')
    users = [(u['Name'], u['Id']) for u in client.get('Users')]
    libraries = sorted(client.get('Library/VirtualFolders'), key=lambda lib: lib['Name'])
    domains = [d.strip() for d in env.get('PRIVATE_DOMAINS', '').split(',') if d.strip()]
    s = Sanitizer(env, domains=domains, users=users,
                  libraries=[(lib['Name'], lib['ItemId']) for lib in libraries],
                  literals={'MEDIA_ROOT': env.get('MEDIA_ROOT', ''),
                            'JELLYFIN_DATA': info.get('ProgramDataPath', '')})

    files = {}
    files['server.json'] = s.sanitize(
        {'Version': info['Version'], 'Configuration': client.get('System/Configuration')}, 'server')
    files['repositories.json'] = s.sanitize(client.get('Repositories'), 'repositories')

    plugins = sorted(client.get('Plugins'), key=lambda p: (p['Name'], p['Version']))
    files['plugins.json'] = s.sanitize(
        [{k: p.get(k) for k in ('Name', 'Id', 'Version', 'Status')} for p in plugins], 'plugins')
    skipped = []
    for p in plugins:
        if p['Status'] == 'Superseded':
            continue
        try:
            config = client.get(f"Plugins/{p['Id']}/Configuration")
        except ApiError:
            skipped.append(p['Name'])
            continue
        files['plugins/' + plugin_filename(p['Name'])] = s.sanitize(config, p['Name'])

    branding = s.sanitize(client.get('System/Configuration/branding'), 'branding')
    css = branding.pop('CustomCss', None) or ''
    files['branding.json'] = branding

    files['libraries.json'] = s.sanitize([
        {'Name': lib['Name'], 'CollectionType': lib.get('CollectionType'),
         'Locations': lib.get('Locations', []), 'LibraryOptions': lib.get('LibraryOptions', {})}
        for lib in libraries], 'libraries')

    tasks = sorted(client.get('ScheduledTasks'), key=lambda t: t['Key'])
    files['tasks.json'] = s.sanitize(
        [{'Key': t['Key'], 'Name': t['Name'], 'Triggers': t.get('Triggers', [])} for t in tasks],
        'tasks')

    display = {name: client.get(f'DisplayPreferences/usersettings?userId={uid}&client=emby')
               for name, uid in users}
    files['users-display.json'] = s.sanitize(display, 'users')

    files['placeholders.json'] = sorted(s.used)
    files['ids-allowlist.json'] = sorted(s.kept_ids)
    write(out_dir, files, css)
    return s.new, skipped


def write(out_dir, files, css):
    plugin_dir = out_dir / 'plugins'
    plugin_dir.mkdir(parents=True, exist_ok=True)
    for stale in plugin_dir.glob('*.json'):
        if f'plugins/{stale.name}' not in files:
            stale.unlink()
    for name, obj in files.items():
        (out_dir / name).write_text(json.dumps(obj, indent=2, sort_keys=True) + '\n')
    (out_dir / 'branding.css').write_text(css)


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--env', type=Path, default=ROOT / '.env')
    parser.add_argument('--out', type=Path, default=ROOT / 'snapshot')
    args = parser.parse_args(argv)
    env = envfile.load(args.env)
    missing = [k for k in REQUIRED if not env.get(k)]
    if missing:
        sys.exit('missing in .env: ' + ', '.join(missing))
    client = Client(env['JELLYFIN_URL'], env['JELLYFIN_API_KEY'])
    new, skipped = export(client, env, args.out)
    envfile.append(args.env, new)
    print(f'snapshot written to {args.out}; {len(new)} new value(s) saved to {args.env.name}')
    for name in skipped:
        print(f'no readable configuration: {name}')


if __name__ == '__main__':
    main()
```

```python
"""Fail if files under jellyfin/ contain identifying values.

Checks staged files by default (pre-commit hook); --all checks every tracked
file. Prints file:line and the kind of finding, never the value itself.
"""
import argparse
import json
import subprocess
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import envfile
from sanitize import EMAIL, GUID, PRIVATE_IP, norm_guid

ALLOWLIST = 'jellyfin/snapshot/ids-allowlist.json'


def env_values(env):
    values = []
    for key, value in env.items():
        parts = value.split(',') if key == 'PRIVATE_DOMAINS' else [value]
        values += [p.strip() for p in parts if len(p.strip()) >= 4]
    return values


def scan_text(text, values, allowlist, check_ids=True):
    findings = []
    for number, line in enumerate(text.splitlines(), 1):
        if any(v in line for v in values):
            findings.append((number, '.env value'))
        if PRIVATE_IP.search(line):
            findings.append((number, 'private IP'))
        if EMAIL.search(line):
            findings.append((number, 'email'))
        if check_ids and any(norm_guid(m.group(0)) not in allowlist for m in GUID.finditer(line)):
            findings.append((number, 'unlisted id or key'))
    return findings


def git(repo, *args):
    return subprocess.run(['git', '-C', str(repo), *args], capture_output=True, text=True)


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--all', action='store_true', help='check all tracked files, not just staged')
    parser.add_argument('--repo', type=Path)
    args = parser.parse_args(argv)
    repo = args.repo or Path(git(Path.cwd(), 'rev-parse', '--show-toplevel').stdout.strip())

    if args.all:
        paths = git(repo, 'ls-files', '--', 'jellyfin/').stdout.split()
        read = lambda p: (repo / p).read_text(errors='replace')
    else:
        paths = git(repo, 'diff', '--cached', '--name-only', '--diff-filter=ACMR', '--', 'jellyfin/').stdout.split()
        read = lambda p: git(repo, 'show', f':{p}').stdout

    env_path = repo / 'jellyfin' / '.env'
    if not env_path.exists():
        print('warning: jellyfin/.env not found; checking patterns only')
    values = env_values(envfile.load(env_path))
    listed = git(repo, 'show', f':{ALLOWLIST}')
    allowlist = {norm_guid(i) for i in json.loads(listed.stdout)} if listed.returncode == 0 else set()

    failed = False
    for path in paths:
        for number, kind in scan_text(read(path), values, allowlist,
                                      check_ids=not path.endswith('ids-allowlist.json')):
            print(f'{path}:{number}: {kind}')
            failed = True
    if failed:
        print('check_secrets: identifying values found; commit blocked')
    return 1 if failed else 0


if __name__ == '__main__':
    sys.exit(main())
```

```python
"""Push snapshot/ back to a Jellyfin server. Dry run by default; --apply writes."""
import argparse
import json
import re
import sys
from collections import namedtuple
from pathlib import Path

import envfile
from api import Client
from export import plugin_filename
from sanitize import dashed, fill, norm_guid, slug

ROOT = Path(__file__).resolve().parents[1]
Change = namedtuple('Change', 'label path body differs')
NOT_CONFIGURABLE = {'Superseded', 'Disabled', 'NotSupported', 'Malfunctioned'}


def same(a, b):
    return json.dumps(a, sort_keys=True) == json.dumps(b, sort_keys=True)


def resolve_values(client, env):
    values = dict(env)
    for lib in client.get('Library/VirtualFolders'):
        base = f"LIBRARY_{slug(lib['Name'])}"
        values[base + '_ID'] = norm_guid(lib['ItemId'])
        values[base + '_GUID'] = dashed(lib['ItemId'])
    live = {u['Name']: u['Id'] for u in client.get('Users')}
    for key, name in env.items():
        if re.fullmatch(r'USER_\d+', key) and name in live:
            values[key + '_ID'] = norm_guid(live[name])
            values[key + '_GUID'] = dashed(live[name])
    return values


def plan(client, snap, values):
    read = lambda name: json.loads((snap / name).read_text())
    changes, skipped = [], []

    branding = fill(read('branding.json'), values)
    branding['CustomCss'] = fill((snap / 'branding.css').read_text(), values)
    path = 'System/Configuration/branding'
    changes.append(Change('branding', path, branding, not same(branding, client.get(path))))

    installed = {norm_guid(p['Id']) for p in client.get('Plugins') if p['Status'] not in NOT_CONFIGURABLE}
    for p in read('plugins.json'):
        config_file = snap / 'plugins' / plugin_filename(p['Name'])
        if p['Status'] == 'Superseded' or not config_file.exists():
            continue
        if norm_guid(p['Id']) not in installed:
            skipped.append(f"plugin not installed: {p['Name']}")
            continue
        path = f"Plugins/{p['Id']}/Configuration"
        body = fill(json.loads(config_file.read_text()), values)
        changes.append(Change(f"plugin: {p['Name']}", path, body, not same(body, client.get(path))))

    live_libs = {lib['Name']: lib for lib in client.get('Library/VirtualFolders')}
    for lib in fill(read('libraries.json'), values):
        current = live_libs.get(lib['Name'])
        if not current:
            skipped.append(f"library missing: {lib['Name']}")
            continue
        live_opts = current.get('LibraryOptions', {})
        wanted = {k: v for k, v in lib['LibraryOptions'].items() if k != 'PathInfos'}
        compare = {k: v for k, v in live_opts.items() if k != 'PathInfos'}
        body = {'Id': current['ItemId'],
                'LibraryOptions': {**wanted, 'PathInfos': live_opts.get('PathInfos', [])}}
        changes.append(Change(f"library: {lib['Name']}", 'Library/VirtualFolders/LibraryOptions',
                              body, not same(wanted, compare)))

    live_tasks = {t['Key']: t for t in client.get('ScheduledTasks')}
    for task in fill(read('tasks.json'), values):
        current = live_tasks.get(task['Key'])
        if not current:
            skipped.append(f"task missing: {task['Name']}")
            continue
        changes.append(Change(f"task: {task['Name']}", f"ScheduledTasks/{current['Id']}/Triggers",
                              task['Triggers'], not same(task['Triggers'], current.get('Triggers', []))))

    live_users = {u['Name']: u['Id'] for u in client.get('Users')}
    for key, prefs in read('users-display.json').items():
        uid = live_users.get(fill(key, values))
        if not uid:
            skipped.append(f'user missing: {key}')
            continue
        path = f'DisplayPreferences/usersettings?userId={uid}&client=emby'
        body = fill(prefs, values)
        changes.append(Change(f'display prefs: {key}', path, body, not same(body, client.get(path))))

    return changes, skipped


def main(argv=None, client=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--env', type=Path, default=ROOT / '.env')
    parser.add_argument('--snapshot', type=Path, default=ROOT / 'snapshot')
    parser.add_argument('--apply', action='store_true', help='write changes (default: dry run)')
    args = parser.parse_args(argv)
    env = envfile.load(args.env)
    client = client or Client(env['JELLYFIN_URL'], env['JELLYFIN_API_KEY'])

    required = json.loads((args.snapshot / 'placeholders.json').read_text())
    values = resolve_values(client, env)
    missing = sorted(name for name in required if name not in values)
    if missing:
        sys.exit('cannot restore, no value for: ' + ', '.join(missing))

    changes, skipped = plan(client, args.snapshot, values)
    pending = [c for c in changes if c.differs]
    for change in pending:
        if args.apply:
            client.post(change.path, change.body)
            print(f'updated: {change.label}')
        else:
            print(f'would change: {change.label}')
    for reason in skipped:
        print(f'skipped: {reason}')
    if not pending:
        print('no changes')
    elif not args.apply:
        print('dry run; re-run with --apply to write')


if __name__ == '__main__':
    main()
```

````markdown
# Jellyfin config

The server's configuration lives in `snapshot/`, with every identifying value
(API keys, hosts, domains, users, paths) replaced by a `<PLACEHOLDER>`. The real
values live only in `jellyfin/.env`, which is never committed. Keep a private
backup of `.env` (for example in a password manager) — without it, secrets
have to be re-entered by hand.

## One-time setup (per clone)

```bash
cp jellyfin/.env.example jellyfin/.env   # then fill in the four values
git config core.hooksPath jellyfin/scripts/hooks
```

Create the API key in Jellyfin: Dashboard → API Keys → +, name it `config-snapshot`.

## Taking a snapshot

```bash
python3 jellyfin/scripts/export.py
python3 jellyfin/scripts/check_secrets.py --all
git add jellyfin/snapshot && git commit -m "jellyfin: snapshot"
```

The pre-commit hook blocks the commit if anything identifying slipped through.

## Making a change (so it can be reverted)

1. `export.py`, commit `jellyfin: snapshot before <change>`.
2. Make the change (files in `custom/` and/or the dashboard).
3. `export.py`, commit `jellyfin: <change>`.

To undo: `git revert <commit>`, then
`python3 jellyfin/scripts/restore.py` (dry run) and `--apply`.
If the change installed a plugin, uninstall it in Dashboard → Plugins and restart.

## Rebuilding a server from scratch

1. Install the Jellyfin version in `snapshot/server.json` (`Version`).
2. Create the users with the same names as in `.env` (`USER_1`, `USER_2`, …).
3. Create each library from `snapshot/libraries.json` with the same name, type and
   folders (`<MEDIA_ROOT>` = `MEDIA_ROOT` in `.env`).
4. Dashboard → Plugins → Repositories: add every entry in `snapshot/repositories.json`.
5. Install every plugin in `snapshot/plugins.json` whose `Status` is not
   `Superseded`, at the listed `Version`; leave `Disabled` ones disabled.
6. Restart Jellyfin.
7. Create an API key, put it and the new URL in `.env`.
8. `python3 jellyfin/scripts/restore.py` — read the list, then run again with `--apply`.
9. Restart Jellyfin, then run `restore.py` once more: it should print `no changes`.

## What is not covered

- Watch history, favourites, user passwords and the Jellyfin database.
- Media files, metadata and artwork.
- `snapshot/server.json` is a reference copy of the server settings; restore does
  not write it. Re-apply anything you need from it by hand in Dashboard → General.
- Per-user Home Screen Sections overrides that the plugin stores outside
  display preferences.
````
